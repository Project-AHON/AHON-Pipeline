# Findings and interpretation

This page records verified analytical findings, not proposed calculations. No validated composite LGU risk or preparedness rankings are published here.

Each finding must include:

- Question and interpretation.
- Dataset and table.
- Reference period and PSGC snapshot.
- Repository commit and [run evidence](../operations/pipeline-runs.md).
- Query or calculation.
- Coverage, missingness and quality limitations.

Source-profile counts and historical DQ observations must be labelled as such. They are not evidence of current production state or LGU preparedness.
