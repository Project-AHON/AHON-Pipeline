# Guide for LGU evidence review

AHON exposes earthquake observations, population counts, selected CMCI indicators, OSM source features and reported disaster funding. These help organize evidence for planning. Current outputs do not classify LGU earthquake risk, vulnerability or preparedness.

Start with a selected LGU PSGC code and reference year. Check geographic match status, source snapshot, missing measurements and completeness before comparing values. Missing data means unavailable evidence; it does not mean zero population, zero resources or poor performance. A listed locality near an earthquake is a textual candidate and does not identify the exposed LGU.

Population totals describe residents, funding utilization describes spending against budget, and CMCI fields describe their source indicators. Interpreting these as preparedness requires units, directionality, benchmarks and domain review. See the [question-to-evidence mapping](../architecture/metrics.md) for what remains unresolved.
