# PHIVOLCS observation contracts

Source: monthly PHIVOLCS listings, requested by inclusive year-month window. The extract preserves the publisher's eight displayed fields in CSV: Date-Time, Latitude, Longitude, Depth, Magnitude, Location, Month, Year. Completed landed files carry SHA-256 and source-row counts; incomplete downloads are not readable by Bronze.

`bronze.philvolcs_earthquake_observation` retains the eight fields as strings, `_source_row` ordinal, and all five standard provenance fields plus `_source_digest` and `_observation_id`. Observation identity is file digest + row ordinal, retaining even identical duplicate rows. Row hash covers the source fields using explicit null-aware JSON serialization; it is not an event key.

`silver.philvolcs_earthquake_observation_clean` retains observation identity and raw values while adding `event_time` TIMESTAMP_NTZ (listing wall-clock time), latitude/longitude DOUBLE (degrees), `depth_km` DOUBLE, magnitude DOUBLE (publisher's unspecified magnitude scale), `source_year`/`source_month` INT, `has_dq_issues` and `_processed_at`. Missing or malformed time/coordinates/depth/magnitude, nonfinite values, out-of-range coordinates, negative depth/magnitude and period mismatch are flagged. Every observation remains; flagged rows are also retained in `silver.philvolcs_earthquake_reject`.

Locality/province tokens, sorted `candidate_codes`, `candidate_status` and `_psgc_snapshot` describe exact textual candidates for the configured reference. Status is `unparsed`, `unmatched`, `ambiguous` or `single_candidate`; ambiguity is preserved as an array. `psgc_code` is always NULL and assignment status is `WITHHELD_LOCALITY_IS_NOT_EXPOSURE`. Candidate joins are one row per observation; no name-only fallback is used.

Gold event processing is blocked until publisher/event identity, duplicate/correction eligibility and time interpretation are approved. Current counts represent observations. `platinum.earthquake_observation_summary` reports valid/invalid and textual-match coverage by source month/year, with maximum reported magnitude over valid observations. These outputs are not LGU event counts, exposed population or validated risk.
